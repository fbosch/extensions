# Wowhead

Browse retail Wowhead entities directly from Vicinae.

## Features

- Universal search across common Wowhead entity types
- Type filtering for items, NPCs, quests, spells, achievements, objects, zones, factions, currencies, recipes, and guides
- Lightweight detail preview in the list detail pane
- React Query persistence backed by Vicinae Cache

## Development

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```
